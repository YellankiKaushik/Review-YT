# Contributing

Develop new work from the functional requirements. Do not import the historical application's implementation or pretend its contributions did not occur. Disclose external sources and preserve applicable notices. Keep deterministic source fixtures under tests and never disguise them as live API results.

Use a branch with substantive commits, run the commands in README, and explain user-visible behavior and actual verification. Do not commit `.env`, source snapshots, credentials, databases or generated browser captures. The current license/provenance gate must be cleared before public redistribution. Commit identities and dates must reflect actual work; no artificial contribution history is permitted.
