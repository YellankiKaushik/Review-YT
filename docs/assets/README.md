# Product images and provenance

The PNGs are genuine Playwright/Chromium captures of this application's optimized local production frontend, not generated mockups. Results use explicitly labeled illustrative demo responses and original SVG video artwork; they are **not actual YouTube feedback**. No raw comments, account names, credentials, browser authentication state or filesystem paths are shown. The homepage contains no invented analytics.
